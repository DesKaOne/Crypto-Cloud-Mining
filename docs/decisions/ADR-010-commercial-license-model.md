# ADR-010: Commercial License Domain Boundary

**Status:** Accepted

Crypto Cloud Mining is designed to be distributed as a commercial source-code product.

The commercial model therefore becomes an explicit domain boundary containing Product, ProductVersion, Release, Edition, Customer, License, LicenseActivation, Installation, Entitlement, and Upgrade.

The commercial domain authorizes software usage and version entitlement. It must not become the source of truth for mining balances or the financial ledger.

Payment, billing, marketplace, and customer portal implementation remain future work.
